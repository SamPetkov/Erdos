# Erdős problem research

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

This repository collects self-contained research dossiers on individual
Erdős problems.

## Available dossiers

- [Problem 593](593/) -- the maintained `Erdos593` repository, linked here as
  a Git submodule.
- [Problem 625](625/) -- a proposed full-sequence quantitative resolution of
  the chromatic--cochromatic gap problem for `G(n,1/2)`, with a complete Lean 4
  formalization and a one-file formal proof.

The canonical Problem 625 publication package is in [`625/arxiv/`](625/arxiv/).
Problem 593 submission files remain in [`arxiv_preprints/`](arxiv_preprints/).

Both manuscripts are preprints and have not undergone external peer review.
The repository makes the arguments and supporting material available for
expert scrutiny; it does not assert an official change in the published status
of either Erdős problem.
