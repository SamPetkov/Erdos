# Erdős 625 revised v2 manuscript

Current v2 sources and matching PDF, prepared 13 October 2026. This prepares an arXiv replacement; none has been submitted.

Download [main.pdf](main.pdf) (52 pages) or [Erdos625-v2-arxiv-upload.zip](Erdos625-v2-arxiv-upload.zip). The legacy archive name Erdos625_source.zip contains the same package.

The main text occupies about 36.4 pages. Appendices A–C contain the uniform-root proof, profile-rounding estimates and explicit amplification tail bound. Section 10 retains the mean-excess argument used by the main theorem, including the vertex-exposure proof. Complete supporting arguments remain in the PDF. The shared preprint typography and coloured links are preserved.

This continuation makes 17 editorial changes to the abstract, definitions and proof explanations. It removes repeated wording and explains several terms before use. The graph assumptions, quantifiers, theorem formulas, displayed equations, abstract mathematics, citations and assistance disclosure are retained from the preceding shortened version. No new theorem or Lean-verification claim is made in this pass.

The archive contains main.tex, main.bbl, references.bib and petkov-preprint.sty at the root. Compile main.tex with pdflatex or latexmk -pdf. arxiv-abstract.txt and arxiv-comments.txt provide separate metadata. The exact extracted archive compiles with PDFLaTeX/MiKTeX without warnings or errors. The PDF has embedded fonts, bookmarks and internal/external links.
