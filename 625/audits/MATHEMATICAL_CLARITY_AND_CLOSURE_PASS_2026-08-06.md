### Uniform Stirling remainder

For every nonnegative factorial argument,

```text

|sigma(t)| <= C_S log(t+2).
```

Only a fixed number of factorials occurs because the support has four coordinates. Hence the total error is `O(log n)` uniformly, including when a selected or residual coordinate vanishes.

### Entropy boundary estimate

The exact rounded profile has all four proportions uniformly bounded below. The coordinatewise entropy expression is bounded by

```text

```

and the four-coordinate entropy inequality gives

```text

```

Thus no differentiability at a zero coordinate is assumed.

### Affine phase extraction

Exact subtraction of consecutive `E_i` values gives

```text
E_{i+1} - E_i = -(log 2) alpha / 2 + O(1).
```

Averaging after adding the affine correction isolates the only term needed from the positive complete first moment: a phase-uniform upper bound on the profile average `bar E`. This yields

```text

  <= ((log 2) alpha / 2)(T Y - I) + O(Y).
```

The proof now displays

```text

|I - T Y| <= 3Y,
```

and bounds the difference between `n rho log rho` and
`k_co alpha R log R` by `O(k_co Y)`. This is the missing bridge between the exact factorial variable and the scalar rate variable.
